# 패턴 목록

심각도: **S1** 한 번만 나와도 고친다. **S2** 문서에서 3회 이상 반복되면 밀도를 낮춘다. **S3** 다른 패턴과 겹칠 때만 손본다.
예시는 한다체로 적었다. 출력의 문체 등급은 언제나 원문을 따른다.

| A-13 | S2 | 조사 없는 명사 나열 | 조사 복원. "AI 기술 발전 속도 가속화" 대신 "AI 기술의 발전 속도가 빨라진다" |

| A-15 | S2 | 추상 주어와 만능 동사(보여준다, 제공한다, 가져온다), 사역과 인지 동사 직역 | 구체 주어로. 사역은 "X 때문에", "X 덕분에" 부사절로, suggest나 show류는 "~에 따르면 ~이다" |
| A-16 | S1 | 번역하거나 요약한 글에서만, "그, 그녀, 그것, 그들"이 단락에 3회 이상 | 절반 이상 생략하고 일부는 호칭이나 명사구로. 처음부터 한국어로 쓴 글에는 적용하지 않음 |
| A-18 | S2 | 명사 앞 3어절 이상의 긴 관형구 | 문장을 나누거나 "X를 만났는데, 그 X는"처럼 뒤로 풀기 |
| A-19 | S2 | "~에서의", "~에로의", "~으로의", "~으로부터의" | 절이나 구로 풀기. 단순 "~의"는 대상 아님 |

## K. 작성자 원칙

| ID | 패턴 | 처방 |
|---|---|---|
| K-1 | 내용 없는 도입("급변하는 AI 시대에"), 상투적 맺음말("앞으로가 기대됩니다"), 과도한 칭찬과 감탄, 홍보 문구 | 삭제하고 핵심 문장부터 |
| K-2 | 질문 직후 스스로 답하기("그렇다면 이유는? 바로") | 답을 바로 쓰기 |
| K-3 | 실제보다 개수를 맞춘 세 항목 나열 | 실제 개수대로 |
| K-4 | 격언처럼 만든 문장, 같은 결론 반복 | 삭제하거나 구체 결론 하나로 |
| K-5 | 일반 서술문의 가운데점(·), 엠대시(—), 엔대시(–) | 쉼표, 조사("와", "과", "및"), 마침표, 문장 분리로 |
| K-6 | 일반 서술문에서 빗금(/), 화살표(→), 더하기(+)로 관계 표현 | 말로 풀기 |
| K-7 | "~해야 합니다", "~할 필요가 있습니다" 반복 | 이유와 실행 방법을 쓰기. 서법은 유지하고 반복만 줄임 |
| K-8 | 짧은 글의 제목, 목록, 표, 굵은 글씨, 이모지 | 이해나 검색에 도움이 될 때만 |
| K-9 | 근거 없는 효과나 중요성 과장, 추상적 유행어 | 구체 대상, 행동, 조건, 수치로 |

K-5와 K-6은 공식 명칭, 직접 인용, 코드, 경로, 수식, 표기 규칙에 필요한 기호에는 적용하지 않는다. 원문에 있던 대시도 K-5에 따라 바꾼다. 대시를 지우면 문장 뜻이 흐려지는 경우에만 괄호나 별도 문장으로 옮긴다.
