# AI 티 제거 점검표

초안 완성 직후와 패키징 직전에 본문(표·코드·이미지 alt 제외)을 한 번씩 훑는다. 내용은 한 글자도 바꾸지 않고 문체만 고친다. humanize-korean 플러그인이 설치되어 있으면 그 플러그인의 `references/quick-rules.md`(10 카테고리 70 패턴)와 `metrics_v2.py`를 함께 쓴다(`find ~/.claude/plugins/cache -name quick-rules.md -path '*humanize*'`로 위치 확인). 이 점검표는 그중 격식체 AWS 테크 블로그에서 실제로 걸리는 항목만 모았다. 같은 플러그인의 `/my-plugins:kor-deslop` skill `references/patterns.md`(A~K 79개 패턴)를 같은 기준으로 쓸 수 있고, 이 점검표의 패턴 ID는 그 파일과 같다.

## 번역투

- "~에 대해(서)" → 목적격 조사 직결("X에 대해 논의" → "X를 논의")
- "~를 통해" 문단 3회 이상 → 일부를 "~로", "~해서"로
- "가지고 있다" → 형용사·동사 환원("전문성을 가지고 있으며" — 저자 소개 원문은 예외)
- 이중 피동 "~되어진다", "~에 의해" 피동 → 능동 또는 단일 피동
- "~할 수 있습니다" 남발 → 단언("절감할 수 있습니다" → "절감됩니다")
- 3어절 이상 좌향 수식 관형절 → 문장 분리

## 구조 패턴

- "A가 아니라 B" 대구 2회 이상 → 한 번만 남김
- 문두 접속사(또한/따라서/즉/나아가) 5회 이상 → 대량 제거. "즉"은 문서당 2회 이하
- 결산 어휘(결론적으로/요약하면/정리하자면) → 1~2회로
- 열거 도입("다음과 같습니다", "크게 세 가지로") → 삭제하고 바로 서술
- 연결어미(-고/-며/-지만) 직후 쉼표 → 제거
- 콜론 부제 헤딩 반복 → 명사구로 압축
- 3개 이상 연속 불릿 블록 → 문단으로 통합(전환 절차 같은 순서 목록은 예외)

## 관용구·과장

- "시사하는 바가 크다", "주목할 만하다", "매우 중요하다" → 삭제 또는 구체 결론
- hype 어휘(혁신적/획기적/압도적) → 수치·사실
- 극적 전환("이제는 다릅니다") → 삭제
- 문서 메타 언급("앞서 예고한", "4쪽에 설명했습니다") → 내용 지칭
- 결말 공식("~할 때입니다") → 문서당 1회 이하
- 의인화 추상 주어("기술이 묻는다") → 사람·기관 주어

## 리듬

- 같은 종결어미 4문장 이상 연속 → 한두 문장의 종결 변주("~입니다" 사이에 "~합니다", "~됩니다", 명사형 종결). 격식체 유지가 우선이므로 억지로 바꾸지 않는다
- 문단 안에 단문 1~2개와 인접 문장을 이은 장문 1개가 섞이게(내용 추가 금지)
- 당위("~해야 합니다")로 끝나는 문단이 연속 2개 이상 → 당위 문장을 문단 앞·중간으로 이동

## 완곡·형식명사

- "~로 보인다/판단된다" 남발 → 단언 가능한 곳은 단언
- 이중 완곡("~할 가능성이 있을 수 있다") → 하나만
- "주목할 점은 ~라는 점입니다" → "~입니다"
- "~다는 것입니다/뜻입니다" 결말 → 문서당 2회 이하

## 장식

- 본문 볼드 → 거의 제거(저자 소개 이름 제외)
- 따옴표 강조 5회 이상 → 진짜 인용만
- 대시 부가 설명 → 쉼표·괄호·문장 분리

## 윤문 가드 (2026-11-01 추가, kor-deslop 기준)

문체를 고치는 동안 의미가 바뀌지 않게 지킨다. 아래와 부딪히는 수정은 되돌린다.

- **서법 보존**: 권고("~하는 것을 권고합니다")를 사실("~합니다")로, 추정("예상됩니다", "추정치")을 단정으로 바꾸지 않는다. 같은 서법 표지가 반복될 때는 서법을 유지한 채 위치만 옮긴다
- **문체 등급 유지**: 합쇼체를 유지하고 격식을 올리거나 내리지 않는다. "-했-"을 "-하였-"으로 바꾸지 않는다
- **내용 앵커**: 고치기 전에 문장마다 핵심 명사와 수치를 잡아 두고, 결과에 원형이 최소 한 번 남는지 확인한다. 수치, 단위, 고유명사, 큰따옴표 인용, 코드, URL은 건드리지 않는다
- **빼기 전용**: 윤문하면서 원문에 없던 비유, 상투구, 과장 표현("괄목할 만한", "~로 평가된다")을 새로 넣지 않는다
- **삭제는 후보로**: 문장 전체를 지워야 한다고 판단되면 직접 지우지 않고 사용자에게 삭제 후보로 알린다
- **변경률**: 윤문 전후 변경률이 30%를 넘으면 경고하고, 50%를 넘으면 수정을 줄여 다시 만든다

```bash
python3 -c "import difflib,sys;a,b=[open(f,encoding='utf-8').read() for f in sys.argv[1:3]];print(f'{(1-difflib.SequenceMatcher(None,a,b).ratio())*100:.1f}%')" before.md after.md
```

## 자가 점검 순서

1. `scripts/lint_prose.py <md>`로 금지어, 카운트 항목, 140자 초과 문장 확인
2. `/my-plugins:kor-deslop` 점검만 모드로 남은 패턴 확인
3. 리드와 마치며를 소리 내어 읽는 속도로 훑어 리듬 확인
4. 각 표 뒤 첫 문장이 표 값을 반복하지 않는지 확인
5. 마치며가 리드(또는 제목)의 질문에 실제로 답하는지 확인
